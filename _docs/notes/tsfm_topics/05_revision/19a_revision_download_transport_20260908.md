# 19a. 공식 다운로드 전송 진단 추가 기록

2026-09-08 22:53 KST. 첫 PAYEMS POST는 응답 헤더를 기다리다 30초 timeout으로 실패했다. Form GET HTTP200만 확인되었고, ZIP·값·점수는 아직 없다. 원19 계획 및 첫 실패 기록은 그대로 보존한다.

사용자가 승인한 R1 자료 확보 작업을 이어가기 위해, 같은 공식 endpoint·관측 구간·형식·30초/16MiB 한도를 유지한 작은 전송 진단을 한 번 수행한다. PAYEMS의 선택 vintage만 해당 범위의 첫/마지막 공식일 두 개와 기존 경계일로 줄인다. 별도 probe 폴더에 저장하며 이 응답을 최종 데이터나 점수 입력으로 사용하지 않는다.

목적은 전체 vintage 생성 비용과 POST 경로 자체의 실패를 구분하는 것이다. 작은 요청도 응답 없이 실패하면 자동 POST를 반복하지 않는다. 성공하더라도 원19의 전체 vintage coverage를 충족하지 않은 상태로 성능을 보고하지 않는다. 시간 연장·기간 변경·계열 교체는 이 추가 기록에 포함되지 않는다.
