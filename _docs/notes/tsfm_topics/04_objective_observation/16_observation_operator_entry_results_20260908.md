# 16. 관측 연산 진입 검사 결과

2026-09-08. [고정 계획](16_observation_operator_entry_plan_20260908.md)에 따른 CPU 수학 감사와 USCRN 두 제품의 의미 검증을 완료했다. **알려진 선형 Gaussian 조건에서는 기존 조건부 추론으로 충분했다. 새로운 PEFT 방법이나 예측 성능 개선을 확보한 결과가 아니다.** 실제 자료에서는 마지막 5분 평균의 대응은 확인했고, 시간 평균의 단순 재집계에는 예외 한 건이 남았다.

## 무엇을 실행했나

AR(1) 계수0.8, 과정 잡음 분산0.36, 과거24·미래4, END_BASE/MEAN/SUM 보고서13개 중 원점23까지 도착한12개를 사용했다. 겹치는 구간의 공유 센서 잡음을 포함한 직접 Gaussian conditioning과, 과거·공유 잡음48차원 상태의 순차 Joseph Kalman update를 비교했다. 이는 알려진 모수의 기존 정확 계산이며 학습된 상태공간 모델의 성능 비교가 아니다.

수학 감사는 CPU guard6.078초/exit0, 별도 실제 자료 다운로드·QC는10.094초/exit0이었다. 합16.172초는 두 guard의 합이며 코드 준비·검토·독립 검산까지 포함한 전체 작업 시간이 아니다. GPU 학습·추론·새 학습 업데이트는0회다. ## 수학 결과와 적용 범위

[확인] 직접 계산과 순차 계산의 미래 전체 gain·평균·공분산 최대 차이는 각각4.36e-15,3.89e-15,5.55e-16이었다. 특정 관측값 하나만 비교하지 않고 전체 gain을 비교했다. Mean/sum의 관측값·행렬·잡음 단위를 함께 변환하면 같은 posterior가 나오며, 늦은 보고서 값을1e12로 바꿔도 결과 차이는0이었다.

공유 센서 잡음의 비대각 공분산을 잘못 제거하면 posterior 평균은 최대0.028894, 공분산은0.009945 달라졌다. 이 차이는 잘못 지정한 측정 모형의 영향이다. 새 PEFT의 이득이나 실제 예측 오차 감소가 아니다.

같은 숫자1이라도 과거 한 점 관측과 두 점 평균 관측은 미래 조건부 평균이0.615385와0.765957로 달랐다. 그러나 연산을 아는 기존 선형 head가 두 경우 모두 정확히 표현했다. 관측 metadata가 필요하다는 반례와 내부 모델 적응이 필요하다는 증거는 구분해야 한다.

또한 두 값의 평균만으로 각 값을 정확히 복원할 수는 없다. `(1,−1)` 변화는 평균을 바꾸지 않기 때문이다. 잡음 없는 함수 복원에서의 조건은 `ker(H) ⊆ ker(L)`이며, 이는 미래 과정 잡음까지 복원할 수 있다는 뜻이 아니다. 이 비식별성을 adapter의 학습 실패로 설명해서는 안 된다.

[확인] 모델·자료 검사17개가0.53초에 통과했다. 별도 NumPy52차원 precision 계산으로 저장 결과를 다시 구성한146개 감사도 통과했고 최대 재구성 오차는3.07e-14였다. [독립 수치 감사](../../../../results/peft_observation_operator_entry_v1/independent_audit.json)에 실행한 재검산 소스와 입력 SHA를 보존했다. 같은 구현 담당자가 별도 공식·프로세스로 수행한 검산이며 완전히 다른 작성자의 재현이라고 표현하지 않는다.

판정은 `EXISTING_LINEAR_CONDITIONING_SUFFICIENT`다. 이 알려진 Gaussian 사례에서 새 학습 방법을 만들지 않는다. 비선형 실제 시계열이나 동결 FM의 prior가 유용할 가능성까지 닫은 판정은 아니다.

## 실제 관측 자료에서 확인한 것

값을 보기 전에 Tucson `AZ_Tucson_11_W`의2024년 hourly/subhourly 두 URL과 크기·시간 상한, 소스·계획 SHA를 [다운로드 전 계약](../../../../data_external/uscrn_operator_entry_v1/contract.json)에 고정했다. 두 응답은HTTP200, 크기는2,143,296/14,230,080bytes로 합16,373,376bytes였다. 다운로드 뒤 다른 station/year로 교체하지 않았다. URL·Last-Modified·raw SHA와 전체 집계는 [QC 결과](../../../../data_external/uscrn_operator_entry_v1/qc.json)에 있다.

[Hourly 문서](https://www.ncei.noaa.gov/pub/data/uscrn/products/hourly02/README.txt)의 T_CALC는 시간 끝5분 평균이고 T_HR_AVG는 시간 전체 평균이다. [Subhourly 문서](https://www.ncei.noaa.gov/pub/data/uscrn/products/subhourly01/README.txt)의 AIR_TEMPERATURE는5분 평균이다. 따라서 여기서 END_BASE는 물리적인 순간 온도가 아니다.

[확인] 같은 WBAN53131·CRX2.623에서 hourly8,784행, subhourly105,408행을 확인했다. 중복 timestamp와 구간 내 격자 누락·격자 이탈은0이었다. 기온 결측은 hourly T_CALC697개, T_HR_AVG699개, subhourly8,368개였다.

실제 파일의 시작은 각각2024-01-01 01:00/00:05이고 끝은 모두2025-01-01 00:00이었다. 후자의 달력 연도는2025지만2024년 마지막 구간의 끝 시각이다. 값 조회 전 계획에서 예상했던 ‘첫00:00 hour에 이전 연도 자료가 필요할 수 있음’은 이번 파일에서는 발생하지 않았다. QC의 `year_outlier_count=1`은 이 구간 끝 한 건을 세는 문자 그대로의 검사이며 잘못된 관측 연도라고 판정하지 않는다. 이전 연도 파일을 추가로 받지 않았다.

[확인] 동일 UTC 시각의 T_CALC와 AIR_TEMPERATURE는 유효8,087쌍 모두 정확히 같았다. 열 이름이 달라도 같은 마지막5분 평균에 대응한다는 증거다.

유효한12개5분 평균과 유효 시간 평균을 함께 비교할 수 있는 구간은8,076시간이었다. 나머지708시간은 비교에서 제외하고 채우지 않았다. 절대 차이 중앙값0.025°C, 평균0.026014°C,95백분위 약0.05°C, 최대0.125°C였다. 한 건이0.1°C를 넘었다. 각각 소수1자리로 반올림한 같은 값들의 산술 평균이라는 가정하에서는 최대 차이가0.1°C 이내여야 하므로, 최대 예외를 단순 반올림이라고 확정할 수 없다. 정확한 센서 유효 개수·제품 집계 처리의 영향은 별도 확인이 필요하다.

[독립 자료 감사](../../../../data_external/uscrn_operator_entry_v1/independent_audit.json)는 생산 QC를 import하지 않고 원문을 다시 파싱해 행 수·결측·유효 비교 수·최대 차이·예외 수를 확인했다. 예외는2024-12-31 02:00 UTC다. 12개 값은 `18.0,17.9,17.6,16.7,15.9,15.3,15.3,15.1,14.8,16.0,15.3,15.0`이고 합192.9/평균16.075°C, hourly T_HR_AVG16.2°C다. Decimal 계산에서도 차이는−0.125°C였다. 현재 공식 문서만으로 원인을 특정할 수 없어 제품 산출·하위 센서 집계 차이 가능성을 미해결로 남긴다. 자료를 바꾸거나 예외를 제거하지 않았다. 작은 histogram 경계·정확한0 차이 개수는 부동소수 합산 순서에 따라 달랐으므로 판단 근거로 사용하지 않는다.

두 자료의 응답 Last-Modified는2025-06-26이다. 이번 archive 비교는2024년 당시 실제 이용 가능 시각이나 수정 전 값의 검증이 아니다. 사전학습 비중복, 배포 지연, 외부 확증 성능도 입증하지 않는다. T_MAX/MIN을 공개5분 평균의 max/min으로 취급하지 않았다.

## 자기 평가와 다음 진입 조건

15번에서 작은 손실 변경의 추가 효과가 없었던 뒤, 이름만 다른 adapter를 만들기 전에 기존 해법이 이미 설명하는 부분을 분리한 것은 필요했다. 그러나 이번 결과 역시 진입 검사이며 사용자가 원하는 ML 방법론 논문 자체는 아니다. 동일한 알려진 Gaussian toy에 학습을 추가하는 것은 주제 탐색의 진전이 되기 어렵다.

다음 좁은 질문은 ‘미세 표적이 없는 대상에서 집계 관측만으로 적응할 때, 동결 FM의 패턴과 단순 보정보다 PEFT가 실제 미세 미래 예측을 개선하는가’다. 이는 아직 채택된 주제가 아니다. 집계 표적만으로 미세 시계열을 추정하는 [Chow–Lin 및 temporal disaggregation](https://journal.r-project.org/articles/RJ-2013-028/)은 강한 기존 대조다. FM 출력을 초기 패턴으로 두고 집계 잔차를 분배하는 조합만으로는 새 기여가 약하다.

또한 미세 target history를 입력하면서 미래 학습 라벨만 감추면, history를 옮겨 같은 미세 라벨을 얻을 수 있다. 실제 관측 제약을 주장하려면 대상의 미세 과거 자체가 없거나 별도의 근거 있는 제약이 있어야 한다. 알려진 미래 집계값을 분해하는 복원과 미래 집계값도 모르는 forecasting도 분리한다. 집계에서 보이지 않는 세부 패턴은 pretrained prior나 고빈도 공변량·공유 동역학 가정에서 온다는 한계를 밝혀야 한다.

정확히 같은 frozen TSFM·PEFT·집계 감독 구성을 이번 제한 검색에서 확인하지 못했다는 사실은 신규성 증명이 아니다. 단순 보정·profile transfer·회귀와 같은 정보 조건의 대조, 미세 라벨 누수 차단, 실제 자료의 관측 계약을 충족하기 전에는 새로운 학습 결과를 주장하지 않는다.
