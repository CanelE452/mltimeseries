# PEFT 주제 반복 탐색: 운영 계약과 자기 평가

2026-09-08. 사용자가 “찾을 때까지 실험하고, 안 되는 주제는 분석·자기 평가 후 다음 후보를 실행”하도록 승인했다. 기존 계획·성능·실패 기록은 보존하고 새 시도에 별도 번호를 붙인다. 이는 논문 채택이나 반드시 양성 결과를 얻겠다는 약속이 아니라, 근거가 있는 방법론 후보를 찾는 지속 작업이다.

## 목적과 완료 기준

최상위 목적은 foundation model PEFT의 ML 방법론 논문으로 발전시킬 수 있는 구체적인 문제와 방법을 확보하는 것이다. 진단 보고서 작성이나 특정 benchmark의 양성 수치만으로 완료하지 않는다. 소비처는 연구 방향을 정할 사용자와 논문 검토자다.

완료를 주장하려면 (1) 명확한 배포 조건에서 기존 방법의 반복적 미해결 문제, (2) 가장 가까운 선행 방법과 구분되는 구현, (3) 동일 정보·선택·계산 조건의 강한 단순 대조 및 관련 방법 비교, (4) 핵심 구성의 삭제 대조와 경쟁 설명 구분, (5) 방법 선택 후 유보 원천 또는 독립 backbone의 재현, (6) 실패 범위·비용·불확실성 기록이 필요하다. 이 기준을 완화해 이미 얻은 결과에 맞추지 않는다. 논문 채택 자체를 보장할 수는 없다.

모든 후보는 개별 실행 전 비교·선택·중단 기준을 저장한다. 개발 결과를 본 데이터는 이후 확증 holdout이라고 부르지 않는다. 여러 후보를 시도한 횟수와 음성 결과를 남기고, 선택 후 새 평가에서 확인한다. 한 후보의 계획된 screen과 원인 진단을 끝내면 계속 튜닝할지 중단할지 명시하며, 실패한 후보를 이름만 바꿔 재실행하지 않는다.

## 이전 주기에 대한 자기 평가

[10번 결과](10_peft_trainlag_results_20260908.md)는 같은 train label로 추정한 지연 회귀가 oracle에 근접함을 보였다. 따라서 이 Gaussian 조건에서 새 adapter 필요성을 찾는 작업은 중단한다. 앞선 접근의 약점은 FM 내부 상대 개선에 집중하고 구조적 단순 풀이의 이점을 늦게 제거했다는 점이다. 이후에는 단순 풀이와 기존 연구의 해결 범위를 더 먼저 점검한다.

기존 실데이터 A1은 ETT/Jena 두 개발 패널·32일 평가에서 INCONCLUSIVE다. 이를 PEFT 전체의 반증으로 옮기지 않는다. B의 선택 변동은 미래 regret가 있어야 문제이며, C의 calibration 하락은 실제 필요한 예측 품질인지와 간단한 보정으로 해결되는지부터 확인한다.

## 현재 후보와 실행 순서

1. **C: proper score 적응 후 구간 품질.** 10번 ALIGN_ATTN의 80% coverage가 약70%였다는 직접 관찰이 있다. 먼저 기존 예측의 CPU 보정으로 해결 여부를 검사한다. 기존 평가를 이미 봤으므로 탐색적 폐쇄 진단이며 외부 확증이 아니다. 단순 보정으로 해소되면 이 현상만을 위한 새 PEFT 제안은 보류한다.
2. **A의 외부 원천 검사: 단순 출력·입력 풀이를 넘는 적응.** 기존 ETT/Jena와 synthetic 외의 실제 원천을 조사하고, 선택용 데이터와 calibration 데이터 및 미래 평가를 시간순 분리한다. 관련 source/family가 기존 실험에 소비됐는지 먼저 확인한다. 구체적인 데이터·예산은 다음 별도 계획에 고정한 뒤 실행한다.
3. **B: 제한된 검증 기간의 PEFT 선택 regret.** 여러 후보가 달리 선택된다는 사실만으로 진행하지 않는다. 고정 LoRA/시간 분리 validation/early stopping을 넘는 미래 regret가 있는지 검사할 후보로 유지한다. 모델 선택 불확실성을 쓰는 아이디어 자체는 신규성이 아니다.

추가 가설은 “새 내부 adapter 대신 pretrained 분포의 shape를 재사용하면 적응 중앙값의 개선과 구간 품질을 함께 얻을 수 있다”이다. 이는 복잡한 PEFT를 덜 요구한다는 점에서 반대 후보지만, 작은 데이터에서 분포의 tail을 재학습하지 않는 이점이 있을 수 있다. 기존 분포 보정·모델 결합과 가까우므로 이번에는 단순 보정 대조로 먼저 취급한다.

## 선행연구 진입 검사

- [Chronos-2 Gated-LoRA, arXiv2608.11359v1](https://arxiv.org/html/2608.11359v1): source LoRA를 고정한 market-state gate, CRPS 개선과 PICP80 악화를 함께 보고한다. 현상 자체나 상태별 강도 조절을 새 발견으로 주장하기 어렵다. arXiv 공개본이며 채택을 확인한 것은 아니다.
- [TimeTic, arXiv2509.23695v1](https://arxiv.org/html/2509.23695v1): 정보량·비중복성과 불확실성을 활용한 TSFM 전이 성능/모델 선택을 다룬다. 한 backbone 내 LoRA 선택과는 질문이 다르지만, 단순한 불확실성+중복도 결합은 충분한 신규성 근거가 아니다.
- 기존 [PEFT 사전조사](../../reference/time_series_peft_research_dossier_20260907.md)의 LIFT/UniCA/TRACE/MixFT/WiSE-FT 및 calibration 대조 범위를 이어받는다. 원문과 구현의 확인 범위를 구분한다.

## 안전·권한과 기록

기존 사용자 승인은 후보 선택·실험·분석·다음 후보 실행을 포함한다. 매 주기 계획은 파일에 남기되 동일한 실행 승인을 다시 요구하지 않는다. 기존 실험 소스·계약은 동결한다. 새로운 GPU 작업은 root가 공유 guard로 한 개씩 실행한다. 별도 사용 중인 프로세스, 드라이버, Defender 등 시스템 설정은 변경하지 않는다. Commit/push는 하지 않는다.

14:36 KST 조회에서 GPU는 RTX4070, 1198MiB/46°C, 공유 guard lock 없음이었다. 관련 없는 trading/Blender MCP 프로세스는 유지했다. 실제 학습 직전 다시 자원과 live process를 확인한다. 오류가 나면 해당 로그를 보존하고 실패 원인 수정 후 새 경로에서 재개한다.

각 완료 주기에는 질문, 실제 실행 수, 선택/평가 노출, 결과, 반례, 자기 평가, 다음 실행 이유를 기록한다. 아직 검증되지 않은 성공은 `CANDIDATE`이며 전체 goal은 계속 active로 유지한다.
