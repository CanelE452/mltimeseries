## 정정 — "수렴하지 않았다"는 내 판단이 틀렸다

위 "결과 해석을 제한하는 것 두 가지 (1)" 에서 `best_epoch` 이 42–49 of 50 이라는 것만
보고 "어떤 arm 도 수렴하지 않았다 / val 이 계속 내려가는 중에 50 epoch 상한에 걸렸다"
고 썼다. 곡선을 열어보지 않은 [추정]이었고, 열어보니 틀렸다.

21 fit 전부 epoch 40 이후 평탄면이다.

| 지표 | 21 fit 범위 |
| --- | --- |
| epoch 40–49 평균 대비 best 이득 | 0.12 – 1.09% |
| 마지막 10 epoch 선형 기울기 | −0.0001 – −0.0007 / epoch |
| 같은 구간 epoch 간 sd | 0.0003 – 0.0023 |

기울기가 잡음과 같거나 작고, `ep40 평균` 과 `last10 평균` 이 소수 5자리까지 일치한다
(예: P seed 2026090601 둘 다 0.27287). patience 8 이 한 번도 발동하지 않은 이유는
학습이 진행 중이어서가 아니라 **개선 임계값이 `1e-6` 인데 평탄면 잡음이 ~0.001 이라
카운터가 계속 리셋됐기 때문**이다. early stopping 설계의 문제이지 예산 부족이 아니다.

이 정정은 결론을 약화시키지 않고 강화한다 — P vs D, P vs P_BROKEN 이 덜 학습된 모델
끼리의 비교가 아니라 평탄면에 도달한 모델끼리의 비교였다는 뜻이다.

대신 다른 한계가 남는다. **checkpoint 를 잡음 섞인 평탄면의 최소점에서 고르므로 arm별
val 수치가 평탄면 잡음만큼(상대 0.4–0.8%) 낙관 편향돼 있다.** 모든 arm 이 같은
프로토콜을 쓰므로 대비를 계통적으로 왜곡하지는 않으나, 단일 arm 수치를 소수 3자리로
읽으면 안 된다. 그리고 P over D 의 −1.19% 는 이 평탄면 잡음과 같은 자릿수라
단독으로는 무겁게 실을 수 없다 — 그래서 P vs P_BROKEN(−0.05% [−0.26, +0.17])이
결정적인 대비다.

v2 를 한다면 epoch 를 늘릴 게 아니라 early stopping 임계값을 잡음 규모에 맞추고
(예: `min_delta = 1e-3`), checkpoint 를 마지막 k epoch 평균으로 고르는 쪽이 맞다.

### oracle headroom 을 candidate 없이도 계산한 이유와 결과

여기서 멈췄으면 "cross-model complementarity 가 열려 있다"고 잘못 보고했을 것이다.

`oracle_exploitability.py` 로 두 가지를 검정했다 — 승자 지속성(우연 대비 초과)과
과거만 쓰는 per-series router. 두 split 이 같은 답을 준다:

| | discovery | confirmation |
|---|---|---|
| 평균 oracle headroom | 5.60% | 6.48% |
| per-series router 회수 | −1.85% | −1.46% |
| 승자 지속성 초과(우연 대비) | +0.0059 (6,300쌍) | +0.0270 (15,644쌍) |

origin 마다 3개 손실의 최소값을 고르면 세 모델이 구별 불가능해도 항상 이득이 난다.
승자는 시계열의 성질이 아니라 매 window 다시 뽑히고, 과거 승자를 따르는 router 는

(지속성 +10.8%p, router +1.5%) — 단서일 뿐 결과가 아니다.

### 코드 변경 (이 세션)

- `run_models.py` — 예측 quantile 저장(P3/P6 probe 용), window 별 집계로 수정, task 간
  `gc.collect()` + `empty_cache()`, `known_columns_used/skipped` 기록.
- `scoring.py` — `task_aggregate()` 추가. fev 의 `test_error` 는 **window 별 점수의 비가중 평균**인데
  per-origin 집계가 window 를 item 수로 가중하고 있었다(ecdc_ili 2.5e-3 불일치). 수정 후
  16/18 task 가 1e-6 미만(하한 1.6e-8 = float32 저장), 나머지 2개(kdd_cup, uci_air_quality)는
  3.7e-3 — target 별 ground-truth 결측률이 달라 fev 의 차원별 평균을 item 평균으로 표현할 수 없기 때문.
- `models.py` — TimesFM 다변량 출력 reshape 에서 `np.atleast_3d` 오용 수정((H,Q)→(H,Q,1) 이 되던 것),
  변량 수 검증 추가.
- `probes.py` — baseline 비교자를 task 별 사후 최적이 아니라 **전역 단일 모델**로 고정,
  P5 covariate ablation 추가, all-NaN 방어.
- `run_probes.py` — 단순 처리는 candidate 의 **모든** task 를 덮을 때만 후보로 인정.
- `select_tasks.py` — 규칙 교체(모델 실행 전): `(domain, frequency)` round-robin + dataset family 당 1개.
- 신규: `characterise.py`, `oracle_exploitability.py`, `uncertainty.py`, `publication.py`,
  `drive_discovery.sh`, `drive_confirmation.sh`.
